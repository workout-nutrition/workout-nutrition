# Workout Nutrition & Next Level Fitness

Premium sports supplement e-commerce storefront and integrated Next Level Fitness gym microsite built with React 19, TypeScript, Tailwind CSS v4, and Supabase.

> 📄 **Complete Technical Documentation for AI & Developers:**
> Please see [**CLAUDE_PROJECT_OVERVIEW.md**](./CLAUDE_PROJECT_OVERVIEW.md) for the exhaustive A-to-Z tech stack, features list, database schemas, tables, dependencies, file tree, and architecture specifications.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Key Technologies
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Motion (Framer Motion), Lucide React
- **Backend & Database:** Supabase (PostgreSQL, Supabase Auth, Supabase Storage, Edge Functions)
- **Tooling:** Vite 8.3
